
# Email/SMS Spam Detection

## Project Overview
An Email/SMS Spam Detection application built using Machine Learning and Streamlit. It classifies messages as Spam or Not Spam.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- NLTK
- TF-IDF Vectorization
- Scikit-learn
- Streamlit
- Pandas
- NumPy

## Features
- Text preprocessing
- Tokenization
- Stopword removal
- Stemming
- TF-IDF vectorization
- Spam message classification
- Interactive Streamlit interface

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
